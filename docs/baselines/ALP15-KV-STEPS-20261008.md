## 预先锁定的实验与门禁

首轮默认 `--clips 2 --steps 10`：固定排序前2clip，每clip三seed，每个clip/seed两个条件：现行repeat-fullprefill10和直接actual-generated-KV10。共12条单轨迹计时请求，不先启动少步探索。

actual cache必须保留 `rope_deltas.detach().clone()`；完整prefix是 `sequences[:,:-1]`、最后token是future-start、actual KV长度必须等于完整prefix长度。专家速度严格复用冻结 `expert_velocity`，它构造独立DynamicCache避免污染VLM原cache。两个条件的生成文本seed均42、轨迹seed为42/43/44、initial-noise SHA必须逐条配对。

fullprefill10先对原 `sampled` helper进行数学对拍，并对旧AWQ同clip/seed完整轨迹复核。actualKV10对fullprefill10：ADE绝对差≤`1e-4m`且轨迹NMSE≤`1e-3`，同时prefix SHA与noise SHA相等。NMSE辅助指标不能替代ADE门禁。

若actualKV10门禁失败：保留已获得的完整坐标/误差，状态 `cache_equivalence_requires_decision`、退出2，停止后续少步。可由独立决策将其作为新口径候选再扩评，不能在现行runner内静默放宽阈值或宣称无损。来源/hash错、缺边界、非finite、旧AWQ/原helper不一致，状态failed、退出1，保留traceback及失败row。

20clip扩评必须提供 `--approved-smoke`，且通过同代码SHA、同运行source SHA、同资产SHA与六项配对门禁。默认只10step；其它步数由主智能体确认后显式传入。每条件完整20×3，缺失、重复或失败行拒绝汇总，绝不以更换noise/clip名单或删除失败通过。

主响应：每clip三seed平均ADE再在clip层聚合；报告mean、clip p95/max、FDE、相对原教师损失。次响应：每请求E2E median/p95、分阶段同步wall时间、MemoryRecorder allocated/reserved/RSS、实测storage分组。没有把seed当独立clip，没有开展功效推断或确认性泛化检验。

首轮门禁有依赖顺序：fullprefill10→actualKV10；后续step按显式CLI顺序执行。固定顺序与共享GPU训练可能混杂时间漂移；这些wall时间只作瓶颈诊断，不能据此做候选速度显著性排序或Orin延迟验收。

## 计时、加载与存储边界

每一row只生成一条轨迹，独立重跑 `rawimages→processor→history fuse→generate→Expert sample→action_to_traj`。各阶段和完整E2E都在CUDA同步后计wall；E2E直接测整段实际wall，不把多个seed的phase总时长称E2E。

磁盘数据decode另记；模型加载、checkpoint/资产哈希、raw prompt/cache等价检验、noise digest、数值坐标/指标/旧helper复核另记。计时generate只复制冻结helper的生成参数/停止边界，CPU输入回拷、digest、text decode移出计时；新轨迹与原helper/frozen AWQ门禁验证它未改变数学口径。所有首请求/冷态内存记录保留。

临时采用原BF16 loader→step400 overlay→252 existing packed替换；冷加载phase明确单列，不能称packed-only可部署loader。repeat-fullprefill条件在重prefill前释放生成actual KV，与原AWQ路径一致。实际tensor底层storage按VLM language/visual/lm_head/embedding、Expert、action projection/trajectory等分组去重；共享storage只计一次并列明全部alias。不用参数数或checkpoint磁盘大小猜显存，不把RSS与CUDA峰值相加代替Orin统一内存。
