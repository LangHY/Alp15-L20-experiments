## 3. C1/C2/C3 的独立代数与适用条件

### C1/C2

固定有限QC框的clip响应D_i是固定值。C1 SRSWOR的 `Var(Dbar)=(1−n/M_Q)S_D²/n` 和无偏样本方差估计适用；不需要另假设道路clip响应相互独立。道路超总体泛化仍不能由此获得。

C2在**固定且对所有metadata clip有定义的Q**下，均匀随机排列的前n个合格ID恰是E_QC上的SRSWOR，须M_Q≥n、无行政/费用跳过、无按先遇顺序改变去重代表。M_Q未知不影响这个对称性，但不使π数值/FPC已知；Q依赖模型误差、人工替补或获取中断后补便利数据会破坏前提。达到预算上限则incomplete，不换便宜clip完成n；任何条件于“恰好可完成”的范围声明也须披露获取censor，不能由本代数认证。

本轮独立枚举metadata5个ID的120种排列，固定Q通过{0,2,4}、n=2，三个合格子集各40次，与v2相符。另复算M=10、n=4、D=[−3/20×9,17/20]全部210子集：E(Dbar)=−1/20，S_D²=1/10，真实Var=E(FPC估计)=3/200；省FPC的E(s_D²/n)=1/40≥3/200。**这只是期望关系，不是每份样本保守，更不是CI覆盖证明**：未取到稀有clip的样本会有s_D²=0。v2已经正确限制了这个结论。

### C3

前提是H个非空QC块和每块M_g均已知，一级G块SRSWOR、各入选块二级独立SRSWOR，n_g事前给定且不按响应修改；M_Q=ΣM_g。这不是当前633个metadata块已经完成QC的声明。若QC域规模未知，只能走另行推导的域估计设计，不能拿当前示例权重照套。

令 `tau_g=Σ_g D_i`，`V_g=M_g(M_g−n_g)S_Dg²/n_g`，S_tau²为H个真块总量的有限总体方差。全概率方差给出：

`Var(tauhat_D)=H(H−G)S_tau²/G + (H/G)Σ_g V_g`。

样本块估计总量 `dhat_g=M_g mean_sample D` 的样本方差满足 `E(s_dhat²)=S_tau²+(1/H)Σ_g V_g`；二级样本方差项对V_g无偏。因此v2的

`H(H−G)s_dhat²/G + (H/G)Σ_sample M_g(M_g−n_g)s_Dg²/n_g`

期望正是上述真实总量方差，**没有把二级噪声重复相加**。除M_Q²后为均值方差。HT的S/T总量比是clip总体ratio的设计估计，不是平均chunk ratio，也不宣称ratio估计本身无偏。预锁同一设计的margin仍可线性估计。

## 4. margin/ratio 和校准等号的一个必要澄清

有限均值存在且 `mu_T>0` 时，精确恒等式为：

`mu_D=mu_S−1.15mu_T=mu_T(R−.15)`。

因此ratio≤.15与margin≤0同号等价，不是绝对米制新阈值。mu_T=0时ratio无定义；负分母会反转不等号（真实合法ADE不应为负）；近零/非finite/失败均须按冻结技术规则nonpass。C3须用同一HT权重估计S/T/D，不能拿加权margin与未加权ratio混判。Bonferroni不要求两候选独立，但要求各错误控制有效；A撤销不放宽B。

`U_D(.15)/Tbar`不是ratio的合法上界。对r反演时D(r)的variance含 `Var(S)+(1+r)²Var(T)−2(1+r)Cov(S,T)`，依赖r及分母不确定性；单个margin上界不能除一次随机分母变出整个ratio CI。v2已正确要求同设计检验反演或最终明确采用等价margin门禁。

**需最终校准决策澄清的窄小问题**：用户≤15%含等号，v2主判定允许U_D≤0，但第4.1节把mu_D=0列为null“误通过”校准边界。对于离散/完全普查原子，两种定义不完全相同。精确CPU反例：每clip T=20、S=23，完全普查，R=3/20、D=0、抽样variance=0、合法U_D=0；这是用户边界上的正确pass。若把H0:D≥0包含该情形并把所有pass算错误，其“误通过率”必为1，无法满足.025，尽管有限框值完全已知。

最小修订是在**新的最终校准规格**明确：违约误通过指true R>.15，边界情景用于从违约侧逼近/校准并披露等号原子；若研究选择传统H0:D≥0、严格拒绝U_D<0，则明确这是更严的验证决策，不悄悄把用户≤改成<。不需要回写冻结草案，也不据这个精确例子声称任何近似CI已校准。非退化连续近似下等号概率常为0，但有限框/普查不能默认这一点。

此外，校准网格/MC置信度/情景校正/独立验证、最终临界值和n仍是v2明确pending，不在本轮猜数值。B数量、G数量、无偏variance或少量精确例子都不是覆盖/功效保证。
